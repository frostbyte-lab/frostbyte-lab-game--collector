3. HOSTING EDUNETWORK
---------------------
Edu-network memakai satu Cloudflare Pages project dengan game pada path /game-N/. Pages Functions menyediakan endpoint API dan D1 menyimpan player, saldo virtual, session, spin, result, history, dan statistik.

ZIP harus diekstrak ke slot numerik yang dipilih, misalnya /game-12/. Nomor slot belum ditetapkan di catatan ini agar tidak menimpa game produksi yang sudah ada. Setelah pemasangan:

  npm run prepare-deploy
  git add game-N
  git commit -m "feat(game-N): deploy Wild Bandito EduNetwork package"
  git push origin main

4. KONTRAK API AUTORITATIF
--------------------------
Base API menggunakan same-origin EduNetwork Pages domain. Endpoint yang harus dipakai game:

GET  /api/game/config?game_id=game-N
POST /api/game/init       {player_id, game_id, initial_balance?}
POST /api/game/session    {player_id, game_id}
GET  /api/game/balance?player_id=...
POST /api/game/bet        {player_id, game_id, session_id, amount}
POST /api/game/spin       {player_id, game_id, session_id, bet}
GET  /api/game/result?spin_id=...
GET  /api/game/history?player_id=...&game_id=game-N&limit=20
POST /api/game/collect    {player_id, game_id, session_id}
POST /api/game/bonus      {player_id, game_id, session_id, type, amount?}

5. MAPPING PROVIDER KE EDUNETWORK
---------------------------------
Provider verifySession maps to the EduNetwork init/session flow.
Provider GameName/Get maps to EduNetwork config.
Provider GameWallet/Get maps to EduNetwork balance.
Provider Resources/GetByResourcesTypeIds maps to local ZIP data and EduNetwork config when dynamic data is required.
Provider bet/spin/result/history calls require an explicit schema adapter. URL replacement alone is not sufficient because request bodies and response schemas differ.

6. ADAPTER
----------
File: edu-network-adapter.js

The adapter exposes window.EduNetworkAdapter with config, init, session, balance, bet, spin, result, history, collect, and bonus methods. It uses window.__EDU_ORIGIN__, window.__EDU_GAME_ID__, and the official EduGameClient. It does not emulate provider backend or restore provider balances.

Edu-network middleware injects edu-game-client.js and then edu-network-adapter.js on game slots. The game must call the adapter or EduGameClient; merely placing the file in the ZIP does not automatically translate arbitrary provider API calls.

7. BALANCE AND SECURITY
-----------------------
EduNetwork starts a new player with virtual balance 0. Admin/teacher configuration must provision educational points before spin is playable. Provider real-money balances, credentials, signed CDN URLs, cookies, authorization headers, and license values must never be copied into the hosted package.
