Runbook & API

Kontrak native menempatkan saldo, hasil, dan status transaksi di server. Mock yang tersedia menggunakan data sintetis.

Safe replication. Package ini hanya mereplikasi struktur, schema, UI flow, dan native substitute milik sendiri. Token, cookie, credential, backend pihak lain, DRM, protected binary, dan anti-cheat tidak pernah menjadi dependency release.

Idempotency. Operasi transaksi selalu mengirim request_id dan idempotency_key. Retry tidak menggandakan ledger entry; hasil ditentukan oleh adapter native.
