Game Collector Pro

Collect game resources from web browsers and preview them offline. Powered by Frostbyte Technologies.

Offline-first: Wait 22s · Auto-spins 6 (session+CDN). Tracking dibuang di Collect. ZIP besar → GitHub Actions.

Game URL

Tempel alamat game (http/https) yang boleh dikoleksi. Ini target Capture / GitHub Collect.

Alur offline (tanpa EDU)

1) Set Wait; Auto-spins biarkan 0 untuk asset, atau 3–5 untuk API.
2) ZIP terunduh → Workspace.
3) Workspace: tombol AI / Scan Error / Deteksi AI.
4) Sandbox memakai api-map.json + snapshot untuk mock lokal.
5) Download ZIP → hosting manual di server kamu.

Wait after load (detik)

Waktu tunggu setelah halaman terbuka agar asset & API sempat jalan sebelum di-pack. Game berat: 15–20 detik.

Auto-spins

Berapa kali tombol spin/play diklik otomatis supaya response spin/balance ikut tertangkap. 0 = tanpa spin. Umumnya 3–5.

Delay antar spin (ms)

Jeda antar klik spin (milidetik). Terlalu cepat bisa miss API; default 2200 ms.

Buka History sekali

Untuk Collect via GitHub: coba buka panel history game sekali agar endpoint history ikut tercapture.

Capture (Cloudflare)

Collect di Worker (Playwright). Cepat untuk paket kecil/sedang. Progress & ZIP langsung di web ini. Jika terlalu besar → gunakan GitHub.

Collect via GitHub

Jalankan workflow Actions (auto-spin lebih kuat, cocok ZIP besar). Status tetap di halaman ini; tidak perlu buka tab GitHub.

Clear

Reset teks status / panel live capture di halaman Collect (tidak menghapus ZIP di Workspace).

Resume missing (muncul jika belum lengkap)

Setelah collect, jika ada file kurang, tombol Resume mencoba fetch ulang referensi yang hilang tanpa collect dari awal.
