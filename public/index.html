Game Collector Pro
Cara kerja sistem (Collect → Preview offline)

Game Collector Pro menjalankan game di browser otomatis, mengambil kode & asset, lalu bisa dimainkan offline.

  1. Collect — sistem buka URL game dengan browser headless (Playwright).
  2. Halaman di-load, di-scroll, resource yang muncul dicatat (HTML, JS, CSS, gambar, audio, font, data).
  3. Path diubah ke lokal, frame-buster dinetralisir, bootstrap offline disisipkan.
  4. Semua dikemas jadi ZIP siap offline.
  5. Workspace — load ZIP, lalu Preview (Sandbox / Protected / Hybrid / SW Proxy / Window).
  6. Game jalan di browser kamu tanpa server dan tanpa API game asli.

Dua jalur Collect (tanpa R2):

  • Capture (Cloudflare) — cepat untuk paket kecil/sedang (aman ~20–25 MB ZIP). Ada limit browser Free ~10 menit/hari.
  • Collect via GitHub — untuk game besar / limit browser / TOO_LARGE. Tanpa R2, hasil lewat artifact. Capture otomatis failover ke GitHub jika terlalu besar/limit.

Tidak mengambil backend, database, atau DRM server-side. Hanya resource yang dikirim ke browser.

Tutorial: Collect lewat GitHub Actions

Cara paling stabil, tanpa limit 10 menit/hari.

  1. Buka repo: frostbyte-lab-game--collector
  2. Klik tab Actions
  3. Di kiri, pilih Game Resource Collector
  4. Klik Run workflow (kanan)
  5. Isi form:
    • URL → tempel link game
    • wait_seconds → biarkan 8 (atau 10–15 jika game lambat)
  6. Klik hijau Run workflow
  7. Tunggu status hijau (biasanya 1–3 menit)
  8. Klik run yang baru selesai
  9. Scroll ke Artifacts → download game-resources (ZIP)
  10. Kembali ke web ini → tab Workspace → Load ZIP → Preview

Bagian Preview — panduan & saran

▶ Offline (Sandbox)Mode utama offline. Hanya resource di dalam ZIP. Cocok jika collect lengkap.
⚡ SW OfflineOffline lewat Service Worker (path same-origin). Sering lebih stabil dari blob URL.
🌐 Hybrid OnlineAsset lokal dulu; network server tetap boleh. Untuk game yang masih butuh API live.
🛡 Protected / ⧉ WindowProteksi anti frame-buster / buka jendela terpisah jika iframe diblok.
Load ZIP dulu — saran offline / host / domain muncul di sini.
  • Offline utama: Offline → jika gagal coba SW Offline → Auto Repair Deep
  • Online pun bisa: Hybrid jika spin/login masih butuh server asli
  • ZIP ke server sendiri: Packaging Ulang → extract → upload ke hosting → buka index.html
  • Custom domain: Cloudflare Workers → Domains & Routes (opsional, bukan wajib)
