# Contributing

Thanks for your interest in contributing to frostbyte-lab-game--collector!

How to contribute:

1. Fork the repository and create a branch for your change: `git checkout -b feature/my-change`.
2. Make your changes on the branch and add tests if appropriate.
3. Run tests and linters locally before opening a PR.
4. Open a Pull Request describing your change and link any related issues.

Guidelines:
- Keep changes focused and small.
- Follow the existing code style.
- Include tests for bug fixes and new features when possible.

Security: If you find a security vulnerability, please follow the instructions in SECURITY.md.
